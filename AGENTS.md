# System Roles & Terminology Definition

CRITICAL AND PERMANENT RULE FOR THIS PROJECT:

## 1. Admin = Society Secretary / Society Admin
- **Role**: Administrator / Secretary of a specific residential housing society.
- **Scope**: Manages their individual society — flats, resident directory, approvals, maintenance dues, society expenses, notices, gate logs.
- **Portals & Code**: `admin.html`, Society Admin role in `db.js`, `demo.html` Admin preset (`Jenil Barad - Society Admin`).
- **NEVER** refer to the System Owner / Platform Owner as "Admin".

## 2. Super Admin = System Owner
- **Role**: The overall System Owner / SaaS Platform Owner of Leonex / SocietyHub.
- **Scope**: Controls the entire SaaS platform — manages all registered societies, subscription plans, system-wide analytics, platform owner settings.
- **Portals & Code**: `super-admin.html`, `js/super-admin.js`.
- **MANDATORY COMMUNICATION RULE**: Always use the term **"Super Admin"** when communicating, asking questions, or discussing features related to the System Owner.
