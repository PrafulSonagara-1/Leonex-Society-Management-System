# Project Terminology & Role Rules

- **Admin** = **Society Secretary / Society Admin** (The manager of a specific housing society: flats, residents, maintenance, gates, complaints).
- **Super Admin** = **System Owner** (The platform/SaaS owner: manages all housing societies, subscriptions, global SaaS controls).
- **NEVER** use "Admin" to refer to the system owner. ALWAYS use **"Super Admin"** when communicating or referencing the system owner.
